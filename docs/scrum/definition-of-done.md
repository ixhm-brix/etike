# Definition of Done

A backlog item is done only when all of these are true:

- [ ] **Code reviewed**: at least one teammate approved the pull request
- [ ] **Tests pass**: new behaviour has tests and `pytest` passes
- [ ] **CI green**: ruff and pytest pass in GitHub Actions
- [ ] **Deployed to staging**: it works on the staging server
- [ ] **Documented**: README or `docs/` updated if setup, behaviour or structure changed
