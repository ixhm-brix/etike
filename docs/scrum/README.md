# Scrum at ETIKE

We work in Agile Scrum with short sprints.

## Roles

- **Product Owner**: decides what matters most and keeps the product backlog ordered.
- **Scrum Master**: helps the team follow the process and removes blockers.
- **Developers**: everyone else on Team 3. We build, test and deliver together.

## Sprint length

Set by the team at the first planning session and written in each sprint file. Keep it the same for every sprint so progress is comparable.

## Ceremonies

- **Sprint planning**: pick the sprint goal and the backlog items we can finish.
- **Daily stand-up**: what I did, what I will do, what blocks me.
- **Sprint review**: show the working result (on staging) to the lecturer and stakeholders.
- **Sprint retrospective**: what went well, what did not, one thing to change next sprint.

Each sprint has a file in [`sprints/`](sprints/). Work is only finished when it meets the [Definition of Done](definition-of-done.md).
