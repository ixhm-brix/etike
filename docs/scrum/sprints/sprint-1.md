# Sprint 1: Setup

## Sprint goal

Have a working foundation that every later sprint builds on: the whole stack (Nginx, Flask, PostgreSQL) starts with one command, a landing page is served, `/api/health` reports the system status, and CI and deployment to staging are ready.

## Scope

- Project structure, Docker Compose for local and production
- Flask app factory, config from environment variables, Flask-Migrate initialised
- `GET /api/health` with a database check, plus tests
- Landing page and API helper
- GitHub Actions: CI and staging deploy
- Docs: architecture, Scrum, data rules

Not in scope: login, users, bookings, payments, rides, bus trips, database models.
