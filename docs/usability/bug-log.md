# Bug log

Every problem found in usability sessions (or by the team while preparing them) gets one row. Use participant IDs (P1, P2…), never names.

Each bug is fixed on its own branch (`fix/B1-short-name`) with a test that fails before the fix, then merged by pull request. Put the merge commit in **Fix commit** and set **Status** to `Fixed`.

**Severity**

- **Critical**: blocks a main task (search, book, cancel, rate, post a ride) and there is no way around it.
- **High**: slows or confuses more than one participant, or there is only an awkward way around it.
- **Medium**: one participant struggled, or the wording is unclear.
- **Low**: cosmetic.

**Status**: `Open`, `In progress`, `Fixed`, `Won't fix` (say why in the description).
